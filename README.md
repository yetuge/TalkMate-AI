# TalkMate AI

TalkMate AI is a web-based AI English speaking practice app.

## Development Plan

1. Initialize the Next.js project structure and dependencies.
2. Add scenario data and App Router pages.
3. Build the home page and scenario selection page.
4. Build the basic practice page UI.
5. Add Web Speech API speech recognition.
6. Add AI chat API.
7. Add instant correction API.
8. Add learning report API.
9. Persist sessions with Supabase.
10. Build history and report pages.
11. Polish loading, error, and empty states.

## Getting Started

```bash
npm install
npm run dev
```
